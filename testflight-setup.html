What remains for TestFlight

  1. Active Apple Developer Program membership.
  2. Create the app identifier com.mohammedelghanam.professionalhub and the corresponding app in App Store Connect.
  3. Create an Apple Distribution certificate and App Store provisioning profile.
  4. Create an App Store Connect API key.
  5. Add the signing values as protected GitHub Actions secrets, then run the prepared workflow Build and Upload iOS to TestFlight.
  6. After Apple processes the uploaded build, enable TestFlight testers/public link and replace this status button with the live install link.
No Apple certificate, private key or provisioning profile should ever be committed to the public repository. They must remain in GitHub encrypted secrets.
