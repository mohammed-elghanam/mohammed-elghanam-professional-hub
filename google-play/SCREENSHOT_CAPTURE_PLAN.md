# Google Play Screenshot Capture Plan

Target app: Mohammed Elghanam R&D Hub
Release: 4.0.0+8

Use screenshots from the final signed APK only. Do not use generated UI mockups.

## Capture order

1. **Home / Executive Profile**
   - Show the professional portrait, name/title, and the main navigation/actions.
   - Avoid notification banners, system dialogs, or unrelated overlays.

2. **Projects**
   - Show a representative project list or project detail with readable engineering content.
   - Prefer a screen that demonstrates Embedded Systems / IoT / R&D depth.

3. **Documents / PDF Viewer**
   - Show the Document Library or an opened professional PDF.
   - If possible, include visible Save PDF / Share PDF controls without opening the Android share sheet.

4. **Awards & Recognition Gallery**
   - Show multiple recognition cards/images loaded successfully.
   - Avoid choosing a future-dated visible item if its year could confuse the store reviewer.

5. **Contact & Privacy**
   - Show the Contact page with the Privacy Policy action visible.
   - This screenshot helps demonstrate privacy-policy access inside the app.

## Capture rules

- Use the final signed release `4.0.0+8`.
- Capture on a clean phone screen with normal system font scaling.
- Do not show passwords, private notifications, chat heads, developer overlays, or personal unrelated information.
- Keep screenshots portrait-oriented and consistent in device resolution.
- Preferred preparation target: 1080×1920 when practical.
- Do not add fake UI elements or claims that do not exist in the app.

## Final file names

- `01_Home_Executive_Profile.png`

After capture, upload the five original screenshots without editing. They can then be checked for dimensions, crop safety, readability, and Play Store ordering.
