## Data Safety — important final review

Do **not** automatically submit “No data collected” solely because the app has no account, analytics or advertising SDK.

The Recognition Gallery loads HTTPS images from the Professional Hub web host. Network requests necessarily leave the device, and hosting/security infrastructure may process technical request information such as an IP address and request headers. Google Play defines collection broadly as transmitting user data off the device, including transmission through libraries or SDKs, and treats some ephemeral processing separately.

Before submitting Data Safety, verify the hosting provider’s actual logging/retention configuration. If standard request information is only processed ephemerally for content delivery/security and does not map to a required Play user-data type, document that basis. If the hosting platform retains or uses IP-derived information in a way that maps to a Play data type, disclose it accurately.

Current application review indicates:

- No app account or registration.
- No user-entered forms inside the app.
- No advertising SDK.
- No analytics SDK intentionally included in the Flutter application.
- No location, contacts, camera, microphone, SMS or call-log permission required by normal app functionality.
- PDF viewing is local; save/share actions occur only when initiated by the user.
- Recognition images are loaded from an HTTPS server.
- External email, telephone, LinkedIn and website actions are opened through external device applications/services.
